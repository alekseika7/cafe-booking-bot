# История изменений

## 0.1.0

### Добавлено

- Сервис для Birch, Санкт-Петербург: команды `check`, `run` и `status`,
  Python 3.14, Poetry, Docker Compose с репетицией по умолчанию.
- Автоматическая дата сегодняшнего открытия, подготовка соединения,
  последовательный опрос с учётом `Retry-After`, выбор времени, зала и посадки.
- Контакты и настройки уведомлений в `.env`, шаблон `example_env`,
  конфиг бронирования с пояснениями параметров.
- Проверка контракта виджета, ограниченные повторы подготовки, лимит предоплаты,
  атомарное состояние и блокировка повторной отправки при неопределённом результате.
- Передача ссылки для самостоятельной оплаты и необязательные уведомления Telegram.
- Структурированный журнал без контактов и секретов, pytest с имитацией API,
  ручные бенчмарки в `tests/benchmarks` с локальными отчётами.
- Правила проекта в AGENTS.md, схема последовательности действий и пометка
  об использовании AI в README.

### Исправлено

- Тестовый конфиг больше не копируется из рабочего `config.toml`: изменение
  пользовательского окна визита и посадки не ломает тесты.
- Ошибка чтения слотов в конце опроса даёт `READ_FAILED`, даже если первый
  запрос был успешен. В итоговом событии виден результат последнего чтения.
- Выбор автоматической даты не заменяет режим `dry-run`/`live` в журнале;
  для него используется `date_mode`.
- Ошибочный тип или синтаксис платёжной ссылки даёт `UNKNOWN` с диагностикой
  и запретом повторной заявки. Ошибки токена и ответа слотов имеют явные причины в журнале.
- Из Docker-контекста и Git исключены локальные настройки IDE.
